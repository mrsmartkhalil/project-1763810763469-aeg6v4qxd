# موقع محفظة المحامي أحمد

موقع ويب احترافي باللغة العربية للمحامي أحمد، مبني بتقنية Next.js 15 مع نظام إدارة محتوى متكامل.

## 🚀 المميزات

- ✅ **تصميم عصري وجذاب** - واجهة مستخدم احترافية بتصميم متجاوب
- ✅ **دعم كامل للغة العربية** - جميع النصوص والتنسيقات بالعربية (RTL)
- ✅ **نظام إدارة محتوى** - لوحة تحكم سهلة لإدارة المحتوى
- ✅ **نظام تسجيل دخول** - حماية لوحة التحكم
- ✅ **صفحات متعددة** - الرئيسية، الخدمات، من أنا، اتصل بنا
- ✅ **تصميم متجاوب** - يعمل بشكل مثالي على جميع الأجهزة

## 📦 التقنيات المستخدمة

- **Next.js 15** - إطار عمل React مع App Router
- **TypeScript** - للكتابة الآمنة من الأخطاء
- **Tailwind CSS** - للتصميم والتنسيق
- **React 19** - مكتبة واجهة المستخدم

## 🔐 معلومات تسجيل الدخول

للوصول إلى لوحة التحكم:

- **الرابط**: `/login`
- **اسم المستخدم**: `admin`
- **كلمة المرور**: `admin123`

## 📄 صفحات الموقع

### صفحات عامة
- **/** - الصفحة الرئيسية
- **/about** - من أنا
- **/services** - الخدمات القانونية
- **/contact** - اتصل بنا

### صفحات الإدارة
- **/login** - تسجيل الدخول
- **/admin** - لوحة التحكم (تحتاج تسجيل دخول)

## 🎨 الألوان الرئيسية

- **الأزرق (Primary)**: ألوان الشركة الأساسية
- **الذهبي (Gold)**: للأزرار والتمييزات المهمة
- **الرمادي**: للخلفيات والنصوص الثانوية

## 🛠️ التطوير

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء للإنتاج
npm run build

# تشغيل النسخة الإنتاجية
npm start
```

## 📱 لوحة التحكم (CMS)

لوحة التحكم تتيح لك:

1. **إدارة الخدمات**
   - إضافة خدمات جديدة
   - تعديل الخدمات الموجودة
   - حذف الخدمات

2. **تحديث معلومات "من أنا"**
   - السيرة الذاتية
   - الخبرات
   - التعليم
   - التخصصات

3. **تعديل معلومات الاتصال**
   - رقم الهاتف
   - البريد الإلكتروني
   - العنوان
   - ساعات العمل

## 💾 تخزين البيانات

حالياً يستخدم الموقع `localStorage` لتخزين البيانات (مناسب للتجريب).

**للإنتاج**: يُنصح باستخدام قاعدة بيانات مثل:
- MongoDB
- PostgreSQL
- MySQL
- Firebase

## 🔒 الأمان

**ملاحظة مهمة**: نظام المصادقة الحالي بسيط ومخصص للتجريب فقط.

**للإنتاج**، يجب استخدام:
- NextAuth.js للمصادقة
- تشفير كلمات المرور (bcrypt)
- JWT Tokens
- HTTPS
